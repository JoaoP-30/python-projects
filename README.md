## 📖 Sobre

Este repositório reúne projetos de diferentes níveis de complexidade, criados com o objetivo de consolidar o aprendizado da linguagem Python. Os temas vão desde exercícios básicos de lógica até pequenas aplicações com interface gráfica.

## 🚀 Projetos

| Projeto | Descrição |
|---------|-----------|
| [Alarm Clock](./alarm-clock) | Despertador que permite definir um horário e reproduz um áudio quando ele é atingido. |
| [Banking Program](./banking) | Simulação de conta bancária com consulta de saldo, depósitos e saques. |
| [Simple Calculator](./calculator) | Calculadora que realiza as quatro operações matemáticas básicas. |
| [Concession Stand](./concession-stand) | Simulação de quiosque de lanches com menu e cálculo do total da compra. |
| [Countdown Timer](./countdown-timer) | Contagem regressiva em segundos, exibida no formato horas:minutos:segundos. |
| [Digital Clock](./digital-clock) | Relógio digital em tempo real com PyQt5, no formato 12h com AM/PM. |
| [Encryption Program](./encryption-program) | Criptografia e descriptografia de mensagens usando uma cifra simples. |
| [Interest Calculator](./interest-calculator) | Calculadora de juros com base em valor principal, taxa e tempo. |
| [Mad Libs Game](./madlibs) | Jogo de histórias em que o usuário preenche lacunas com palavras aleatórias. |
| [Quiz Game](./quiz-game) | Jogo de perguntas e respostas de múltipla escolha com pontuação. |
| [Rock-Paper-Scissors](./rock-paper-scissors) | Jogo de Pedra-Papel-Tesoura contra o computador. |
| [Shopping Cart Program](./shopping-cart) | Carrinho de compras simples que soma os preços dos itens adicionados. |
| [Slot Machine Game](./slot-machine) | Caça-níqueis com apostas, saldo inicial e giros dos rolos. |
| [Stopwatch](./stopwatch) | Cronômetro com PyQt5, com botões de iniciar, parar e resetar. |
| [Weight Converter](./weight-converter) | Conversor de peso entre quilogramas e libras. |

## 🛠 Tecnologias

- **Python 3**
- **PyQt5** (usado nos projetos *Digital Clock* e *Stopwatch*)

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/python-projects.git
   ```
2. Acesse a pasta do projeto desejado:
   ```bash
   cd python-projects/nome-do-projeto
   ```
3. Execute o arquivo principal:
   ```bash
   python nome_do_arquivo.py
   ```

> Alguns projetos dependem de bibliotecas externas (como o PyQt5). Nesses casos, instale com:
> ```bash
> pip install PyQt5
> ```
